# Calculator

A simple calculator application made with **Python Tkinter**.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (/)
* Percentage (%)
* Decimal numbers
* Brackets
* Clear (C)
* Calculate result (=)
* Error handling

## Requirements

* Python 3.x
* Tkinter

## How to Run

Run the following command:

```bash
python calculator.py
```

## Usage

1. Enter numbers using the buttons.
2. Select an operation.
3. Press `=` to calculate.
4. Press `C` to clear the screen.
